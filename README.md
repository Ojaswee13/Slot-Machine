# 🎰 Slot Machine

A simple command-line slot machine game built with Python.

## ✨ Features

- 💰 Player balance management
- 🎰 Multiple betting lines
- 💵 Custom bet amounts
- 🎲 Randomized slot results
- 🏆 Payouts based on matching symbols
- 🔄 Play multiple rounds

## 🛠️ Built With

- Python
- `random` module

## 🚀 How to Run

Make sure Python is installed, then run:

```bash
python slotMachine.py
